# 记忆本位积训练

这是一个用于训练记忆本位积技巧的工具，现在可以部署到GitHub Pages上使用。

## 功能特点

- 随机生成3位数题目
- 支持3-8种不同的repo类型
- 提供图像辅助记忆
- 可以验证答案正确性
- 响应式设计，支持移动端使用

## 部署到GitHub Pages

1. 将此仓库推送到GitHub
2. 在仓库设置中启用GitHub Pages
3. 选择正确的分支作为源
4. 访问生成的URL `https://<用户名>.github.io/<仓库名>/`

## 使用说明

1. 选择repo类型（3-8）
2. 查看随机生成的3位数
3. 根据图像记忆规则，输入开头和进位
4. 点击"提交答案"验证结果
5. 点击"下一题"继续练习

## 文件说明

- `index.html`: 主应用页面
- `3.jpg` 到 `8.jpg`: 不同repo类型对应的图像
- `404.html`: 自定义404页面
- `UI.py`: 原始的Python版本（仅作参考）

## 移动端适配

本应用已针对移动设备进行优化：
- 响应式布局
- 适合触摸的按钮大小
- 自动适应不同屏幕尺寸

## 图片路径规范

所有图片都存储在项目根目录下，并使用相对路径引用，确保在任何设备上都能正确加载。
