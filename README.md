## About

I'm **TYSON Pengtao**, building a personal technology lab around the intersection of:

- **Digital Twins** — interactive 3D spaces, realtime state and physical-device control
- **Artificial Intelligence** — AI-assisted workflows, local models and practical automation
- **Engineering Computing** — simulation, spatial systems and technical visualization
- **Automation & IoT** — APIs, MQTT, ESP32/STM32 and real-world device integration
- **Data Visualization** — turning complex systems into interfaces that are easier to understand

My goal is not to collect isolated demos, but to gradually build reusable systems that connect **models → data → decisions → physical actions**.

## Current Build

### TAO Digital Twin

A modular digital twin platform for connecting Web / Three.js and future Unreal Engine scenes with real devices, sensors and automation systems.

Current development areas include:

- React + TypeScript + React Three Fiber
- Three.js interactive 3D environments
- FastAPI backend
- REST + WebSocket realtime communication
- Canonical device / scene-node mapping
- Smart-home device simulation
- Room environmental state
- PET thermal-comfort analysis
- Solar-position and ventilation foundations

Future adapters are planned for **Home Assistant, MQTT, ESP32, STM32, Modbus and OPC UA**.

## Development Direction

```text
3D Models / Digital Space
          ↓
      TAO Core
          ↓
Device State + Environment State
          ↓
Simulation / Analysis / Automation
          ↓
Home Assistant / MQTT / Edge Devices
          ↓
        Reality
```

Near-term focus:

1. Stabilize the digital-twin core and scene model.
2. Improve room-level environmental simulation.
3. Add weather, solar radiation and airflow models.
4. Connect real smart-home devices through adapters.
5. Expand toward Unreal Engine and agricultural digital twins.

---

## Principles

- Build the **framework before feature overload**.
- Keep visualization independent from hardware protocols.
- Separate simulated, requested and confirmed physical state.
- Prefer local-first systems where practical.
- Treat safety as part of architecture, not an afterthought.
